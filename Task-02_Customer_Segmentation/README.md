# Prodigy InfoTech - Task 02
## Customer Segmentation using K-Means Clustering

### 📌 Project Overview

This project is part of my Machine Learning Internship at Prodigy InfoTech.

The objective of this task is to implement a K-Means clustering algorithm to group customers of a retail store based on their purchase-related information.

### 🎯 Objective

To segment customers into different groups based on:

- Annual Income
- Spending Score

### 📊 Dataset

The dataset used for this task is the Mall Customer Segmentation dataset from Kaggle.

Dataset:
https://www.kaggle.com/datasets/vjchoudhary7/customer-segmentation-tutorial-in-python

### 🛠️ Technologies Used

- Python
- Pandas
- Matplotlib
- Scikit-learn
- K-Means Clustering

### 🔍 Project Steps

1. Load the dataset
2. Explore the customer data
3. Select relevant features
4. Use the Elbow Method to determine the number of clusters
5. Apply K-Means Clustering
6. Assign customers to clusters
7. Visualize customer segments
8. Analyze the characteristics of each cluster

### 📈 Features Used

- `Annual Income (k$)`
- `Spending Score (1-100)`

### 🤖 Machine Learning Algorithm

**K-Means Clustering**

K-Means is an unsupervised machine learning algorithm that groups similar data points into clusters.

### 📊 Results

The customers were divided into **5 clusters** based on their annual income and spending score.

The project includes:

- Elbow Method visualization
- Customer segmentation visualization
- Cluster centroids
- Average income and spending score for each cluster
