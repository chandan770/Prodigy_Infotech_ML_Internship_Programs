# 🖐️ Hand Gesture Recognition | Prodigy Infotech Task-04

A real-time **Hand Gesture Recognition System** developed as part of **Task-04 of the Machine Learning Internship at Prodigy Infotech**.

The project uses **Python, OpenCV, MediaPipe, and Machine Learning** techniques to detect hand gestures from a live webcam and map recognized gestures to specific actions.

---

## 📌 Project Overview

The objective of this project is to develop a system that can accurately identify and classify different hand gestures from image/video data.

The system captures live video through a webcam, detects the user's hand, identifies hand landmarks, recognizes the gesture, and displays the corresponding result in real time.
